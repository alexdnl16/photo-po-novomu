# Фото по-новому

Демонстрационный лендинг сервиса, который превращает обычные фотографии в новые образы, фотосессии и места с помощью AI.

## Что внутри

- адаптивный первый экран;
- демонстрационные примеры «до / после»;
- блок возможностей сервиса;
- сценарий «Как это работает»;
- контактный блок для отправки фотографии удобным способом.
- карусель демонстрационных примеров с автоматической сменой.

## Запуск

Откройте `index.html` в браузере. Для работы с GitHub достаточно загрузить содержимое репозитория и открыть этот файл или подключить GitHub Pages.

Перед публикацией замените в `index.html` демонстрационные поля телефона, мессенджеров и почты на свои контакты.

Изображения в папке `assets/demo` являются демонстрационными материалами и не представляют реальные клиентские работы.
